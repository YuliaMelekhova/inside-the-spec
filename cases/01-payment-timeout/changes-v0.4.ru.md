# Case 01: изменения спецификации 0.4

Inside the Spec – Realistic Scenarios. Working Artifacts. Decisions That Matter.

Статус: опубликовано на GitHub. Предыдущая редакция сохранена в истории Git.

| Замечание | Решение |
|---|---|
| Связанные статусы и источник истины | M-01: полный enum зачисления и допустимые сочетания; причины принадлежат review_items, blocking_review_reasons вычисляется |
| Потерянный ответ зачисления, затем hold | CR-01–CR-03: DISPATCHING / OUTCOME_UNKNOWN; hold запрещает новые write, но не lookup чтением и фиксацию проводки |
| Зависшие CREATED / PROCESSING | WR-01: сохранённые задания, watchdog, lease, безопасное закрытие неотправленного запроса, ответственный за передачу |
| Часы восстановления и безопасность create | RP-01: абсолютные сроки, независимый часовой deadline, внешний cutoff 23 часа; основная гарантия неоднозначного повтора PA-01 |
| Отказы webhook и ротация | WH-01: карантин аутентифицированных данных, явные ответы, overlap ключей и экстренный отзыв; базовая ротация уже была в 0.3 |
| Хранение client key | KEY-01: весь срок операции и минимумы после полного разрешения; хранение unresolved уже было в 0.3 |
| HTTP | API-01 осознанно отличается от IETF draft-07: изменённые данные 409, нефинальный повтор 202 |
| Проверенное pending провайдера | IC-14: монотонный provider_operation_seen, вечный запрет новых разрешений CREATE |
| Нет действий пользователя | Допущения и карусель; EUR иллюстративно и не означает освобождения от SCA |
| Пост и карусель | Правило кнопки POST/GET, ключевые артефакты, три связанных измерения, условная liveness, легенда ID и объяснение шести минут |

AC-01–AC-40 сохраняют ID с уточнениями. AC-41–AC-58 проверяют новые границы. Это ожидаемые результаты, а не выполненные тесты реализации. Возможности провайдера/баланса и SLO не проверены на реальной интеграции.

Карусели содержат по 15 страниц с согласованной типографикой. Финальная подготовка подключает проверенные ссылки main, переносит URL из постов в готовые комментарии EN/RU и отмечает публикацию материалов на GitHub. Техническая версия остаётся 0.4. Публикация в LinkedIn ожидается.
